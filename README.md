# jogo_construct3_autech
Projeto desenvolvido na faculdade, utilizando Construct 3.
Aqui você encontra o andamento do desenvolvimento, ideias, prints e versões jogáveis.

<strong>Objetivo:</strong><br>
Criar um jogo interativo sobre desafios de crianças e jovens autistas na realização de tarefas cotidianas essenciais, aplicando conceitos aprendidos na disciplina Projeto Integrador Gamificação. Projeto acompanhado por estudantes do curso de Enfermagem, trazendo informações técnicas mais aprofundadas sobre o tema.

Progresso do Desenvolvimento
- ✅ Conceito inicial definido  
- ✅ Personagem principal criado  
- ✅ Implementação da primeira fase  
- 🔄 Sistema de xp / pontuação 
- 🔄 Sons e trilha sonora
- 🔄 Apuração da jogabilidade
